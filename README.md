## 👨‍💻 About Me

I'm a **Systems Engineering student at Universidad Simón Bolívar** and a **Software Developer trainee at RIWI**, focused on **Backend Development with Java, Spring Boot, and Python / Flask**.

What I do:
- Design **REST APIs** with layered architecture, validation, and relational persistence (PostgreSQL / MySQL)
- Work with **Java 17/21, Spring Boot, Maven, Docker**, and **Python, Flask, Streamlit**
- Build frontend foundations with **JavaScript, Vite, TailwindCSS, HTML/CSS** and mock APIs with **JSON Server**
- Practice **Git, GitHub flow, Postman, ER modeling (MER/MR), and user stories**

What defines me: fast learning, discipline, teamwork, and commitment to efficient, maintainable solutions.
